# 최종 프로젝트 진행 리포트 — 2026-06-22

---

## 진행 상황 요약

후기 작성/관리 페이지의 버그를 대거 정리하고 실데이터 연동을 마무리함. 채팅 페이지에 지원 거절/확정 시스템 메시지, 채팅방 나가기, 사진 전송(Cloudinary) 기능을 추가함. 구인글 작성 시 지도 기반 위치 지정 기능과 마이페이지 프로필 카드 개편이 이루어짐. 결제(payment) 기능 연동도 시작됨.

---

## 주요 성과

- 후기 작성/관리 페이지 더미데이터 제거 및 API 연동, 다수 버그 수정
- 채팅 지원 거절/확정 시스템 메시지 DB 저장, 채팅방 나가기 기능, 사진 전송(Cloudinary 연동) 구현
- 구인글 작성 시 지도 위치 지정 및 도로명 주소 자동완성 구현
- 보호자·펫시터 마이페이지 프로필 카드 개선
- 결제(payment) 기능 연동 착수

## 이슈 및 리스크

### 후기 관리 페이지 무한 로딩

- **증상:** 후기 관리 페이지의 '작성한 후기' 탭이 무한 로딩되는 문제
- **해결:** 데이터 로딩 로직 수정

### 지원 거절 판단 로직 오류

- **증상:** 채팅 지원 목록에서 지원 거절 여부 판단 및 입력 에러 초기화가 잘못 동작하는 문제
- **해결:** 판단 로직 및 에러 초기화 로직 수정

### 프로필 주소/좌표 불일치

- **증상:** 프로필 주소 수정 시 지도상 좌표 및 마커 위치가 실제 주소와 어긋나는 문제
- **해결:** 좌표 갱신 로직 수정

### 다수 브랜치 동시 병합에 따른 충돌

- **해결:** 충돌 해결 후 재병합
