## 이슈 및 리스크

### 1:1 채팅방 양방향 중복 생성

- **증상:** 지난 코드 리뷰에서 지적된 대로, 양쪽에서 채팅을 시작할 경우 1:1 채팅방이 중복 생성되는 문제
- **해결:** 채팅방 생성 로직에 중복 방지 처리 추가

### 지원 거절 상태 미반영

- **증상:** 보호자가 예약 내역에서 지원을 거절해도 새로고침하지 않으면 화면에 '거절됨'으로 반영되지 않는 문제
- **해결:** 상태 갱신 로직 수정

### realtime 알림 동기화 오류

- **증상:** 알림이 실시간으로 정확히 동기화되지 않는 문제
- **해결:** delta 업데이트 방식 적용으로 동기화 정확도 개선

### 결제요청 카드 중복 전송

- **증상:** 결제 요청 카드를 여러 번 전송할 경우 발생하는 문제들
- **해결:** 중복 전송 방지 및 일반/추가금 결제 카드 구분 표시 추가

### SQL `fee_rate` 기본값 정책 불일치

- **증상:** 12차 코드 리뷰에서 지적된 대로, SQL 상 수수료율 기본값(0.10)이 실제 코드 정책(5%)과 불일치
- **해결:** 기본값을 0.05로 통일
