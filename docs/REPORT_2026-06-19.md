## 이슈 및 리스크

### 회원 탈퇴/복구 로직 오류

- **증상:** DB 구조와 회원 탈퇴 처리 로직이 어긋나는 문제
- **해결:** `users.ts` 액션 및 탈퇴 페이지 로직 수정, 계정 복구(`auth/restore`) 페이지 신규 구현

### 펫 0마리 시 더미 데이터 표시

- **증상:** 로그인 사용자가 등록한 반려동물이 없을 때 더미 데이터가 화면에 표시되는 문제
- **해결:** `mypets/page.tsx` 로직 수정 및 펫 추가 UI 개선

### 게시글 관리 페이지 초기 더미값 표시

- **증상:** 게시글 관리 페이지 진입 시 실데이터 대신 초기 더미값이 먼저 표시되는 문제
- **해결:** 더미값 관련 로직 제거 및 fetch 로직 추가
