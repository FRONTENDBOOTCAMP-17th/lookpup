# 최종 프로젝트 진행 리포트 — 2026-06-10

---

## 진행 상황 요약

API 액션/라우트 레이어 구축을 2차로 확장함. 공통 모달 컴포넌트 시스템(14개 프리셋)을 도입해 여러 페이지에 일괄 연동함. pretendard 폰트를 CDN 방식에서 로컬 번들 방식으로 전환함. 미들웨어 파일 오류와 로그아웃 시 세션 쿠키 미삭제 문제를 수정함.

---

## 주요 성과

- `applications`, `payments`, `requests`, `reservations` 도메인 서버 액션 및 API 라우트 신규 구축
- 공통 모달 컴포넌트(`CustomModal`)와 14개 프리셋 제작, 프로필 설정/회원탈퇴/예약취소/반려동물 삭제/신고 접수/지원하기 확인/후기 등록 등 7개 페이지에 연동
- pretendard 폰트를 `next/font/local`로 전환해 폰트 로딩 방식 개선
- 미들웨어 오류, 로그아웃 세션 쿠키 미삭제 등 버그 수정

## 이슈 및 리스크

### `middleware.ts` 파일 오류

- **증상:** `src/middleware.ts` 파일명 관련 오류 발생
- **해결:** `middleware.ts` → `proxy.ts`로 파일명 변경

### 로그아웃 시 세션 쿠키 미삭제

- **증상:** 로그아웃 처리 후에도 세션 쿠키가 남아있는 문제
- **해결:** `myprofile/page.tsx`에서 Supabase `signOut()` 호출로 세션 쿠키 명시적 삭제

### `feature/modal` 병합 충돌

- **증상:** `feature/modal` 브랜치 병합 시 회원탈퇴 페이지 관련 충돌 발생
- **해결:** `feature/modal`의 회원탈퇴 페이지를 기준으로 충돌 해결
