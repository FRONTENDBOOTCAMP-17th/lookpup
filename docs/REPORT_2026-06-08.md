## 트러블슈팅

### 메인페이지 히어로 플로팅 카드 깨짐 (`fix: 0711c0e`)

- **증상:** 반응형 적용 후 히어로 섹션 플로팅 카드가 레이아웃에서 이탈하거나 다른 요소와 겹침
- **원인:** `position: absolute` 사용 시 부모 컨테이너 높이가 고정되지 않아 뷰포트 크기 변화에 따라 카드 위치 틀어짐
- **해결:** `page.tsx` 컨테이너 구조 재정비 및 반응형 breakpoint별 위치값 명시 (83줄 → 126줄)

---

### OAuth 로그인 페이지 `"use client"` 누락 (`feat: d2f5532`)

- **증상:** `login/page.tsx`에서 `signInWithOAuth` 호출 시 서버 컴포넌트 환경 오류 발생
- **해결:** 파일 상단에 `"use client"` 지시어 추가

---

### OAuth scope 옵션 제거 (`feat: d2f5532`)

- **증상:** 카카오/구글 로그인 시 `scopes` 옵션 명시로 인해 일부 환경에서 인증 오류 발생
- **해결:** `signInWithOAuth` 옵션에서 `scopes` 제거 → 기본 scope 사용

---

### 내 반려동물 페이지 ERD 필드명 불일치 (`fix: f09a1c2`)
