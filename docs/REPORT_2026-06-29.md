## 이슈 및 리스크

### 알림 정렬 오류

- **증상:** `updated_at`이 null인 알림이 최상단에 정렬되는 문제
- **해결:** 정렬 기준 로직 수정

### 알림 목록 이중 새로고침

- **증상:** 알림 목록 클릭 시 `router.refresh()`가 중복 호출되는 문제
- **해결:** 중복 호출 제거

### 1:1 채팅 이동 버튼 미작동

- **증상:** 펫시터가 1:1 채팅으로 이동 버튼을 눌러도 화면이 전환되지 않는 문제
- **해결:** 라우팅 로직 수정

### 게시글 관리 예약 상태 불일치

- **증상:** 게시글 관리 화면에서 완료된 예약의 상태 표시가 실제와 일치하지 않는 문제
- **해결:** 상태 동기화 로직 수정

### 채팅 예약 목록 탭 신고/나가기 오류

- **증상:** 예약 목록 탭에서 신고 URL이 잘못 구성되고, 채팅방 나가기 실패 시 처리가 누락되는 문제
- **해결:** 신고 URL 구성 및 나가기 실패 처리 로직 수정
