## 이슈 및 리스크

### 채팅방 재진입 시 카드 위치 오류

- **증상:** 채팅방 재진입 및 새로고침 후 메시지 로드 시 선택확정/거절 카드 위치가 초기값(채팅 맨 끝)으로 재설정되는 문제
- **해결:** 카드 위치 고정 로직 수정

### 자동 결제 요청 방향 오류

- **증상:** 자동 결제 요청이 보호자→펫시터가 아닌 반대 방향으로 전송되던 문제
- **해결:** 요청 대상 로직 수정

### 예약 완료 카드 실시간 미표시

- **증상:** 선택 확정 시 펫시터 화면에 예약 완료 카드가 실시간으로 표시되지 않는 문제
- **해결:** 실시간 반영 로직 수정
