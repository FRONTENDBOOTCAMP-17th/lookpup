## 이슈 및 리스크

### 발신자 메시지 미표시 및 채팅창 스크롤 불가

- **증상:** 메시지를 보낸 사람 화면에 새로고침 전까지 자신이 보낸 메시지가 보이지 않고, 채팅창 내부 스크롤도 되지 않음
- **해결:** `useChatMessages` 훅 및 `chat/page.tsx` 수정으로 해결
- **참고:** 스크롤 수정 과정에서 입력창 아래로 채팅이 밀리는 새로운 문제가 발견되어 추후 확인 필요로 남김

### 페이지 재진입 시 카카오맵 미표시

- **증상:** 펫시터 찾기 페이지 재진입 시 카카오맵이 재마운트되며 표시되지 않는 오류
- **해결:** 마운트 시점에 `window.kakao?.maps` 존재 여부를 확인 후 재로드하도록 수정

### 채팅 메시지 중복 전송

- **증상:** 메시지 전송 시 `handleSend`가 중복 호출되어 메시지가 여러 번 전송되는 문제
- **해결:** `handleSend` 로직 수정으로 중복 전송 방지

### 406 오류

- **증상:** 반려동물 등록 및 인증 콜백 처리 중 406 오류 발생
- **해결:** `auth/callback/route.ts`, `pet-register/page.tsx` 로직 수정
