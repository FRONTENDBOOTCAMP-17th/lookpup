# 최종 프로젝트 진행 리포트 — 2026-06-24

---

## 진행 상황 요약

가장 많은 기능이 추가된 날로, 돌봄 기록/예약 상세 타임라인, 알림 기능, 활동 반경 기반 위치 시스템이 한꺼번에 구축됨. 공통 위치 선택 컴포넌트와 카카오맵 반경 원 표시를 도입해 펫시터 등록/프로필 수정/프로필 표시 페이지의 위치 입력 방식을 통일함. request_pets 테이블 제거에 따른 타입 오류를 수정하고, Supabase 구조 기준으로 API·스키마 명세서를 갱신함.

---

## 주요 성과

- 돌봄 기록 기능 및 예약 상세보기 타임라인 구현
- 알림 기능 구현 및 돌봄기록 전송 시 보호자 알림 발송
- 공통 위치 선택 컴포넌트 + KakaoMap 반경 원 도입, 활동 범위 필드 추가로 펫시터 등록/프로필 수정/표시 페이지 위치 입력 통일
- 보호자 위치 정보 Supabase 저장 기능 추가
- Supabase 구조 기준 API 명세서 및 스키마 명세서 갱신

## 이슈 및 리스크

### `request_pets` 테이블 제거에 따른 타입 에러

- **증상:** DB에서 `request_pets` 테이블이 제거되며 `applications.ts`에서 타입 에러 발생
- **해결:** 변경된 스키마에 맞춰 타입 정의 수정

### 시터 프로필 반경 값 덮어쓰기

- **증상:** 시터 프로필 수정 시 활동반경을 '상관없음'으로 설정해도 5km로 덮어써지는 문제
- **해결:** 반경 저장 로직 수정

### 모바일 돌봄 기록 버튼 미작동

- **증상:** 모바일 환경에서 채팅 + 패널의 돌봄 기록 버튼이 눌리지 않는 문제
- **해결:** 버튼 이벤트 처리 로직 수정
