# 최종 프로젝트 진행 리포트 — 2026-07-02

---

## 진행 상황 요약

채팅 1:1 방 관련 버그를 중점적으로 정리한 하루. 예약 수락 시 신규 1:1 채팅방이 자동으로 표시되지 않던 문제와 예약 확정 카드가 실시간으로 반영되지 않던 문제를 수정하고, 채팅 배지 스타일을 통일함. 로그인하지 않은 사용자가 보호된 페이지에 접근하지 못하도록 막는 middleware가 새로 도입됨.

---

## 주요 성과

- 예약 수락 시 1:1 채팅방 자동 생성 및 실시간 표시 문제 수정
- 서비스 완료 후 후기 작성 유도 카드 추가, 서비스 진행 중 채팅방 나가기 제한 로직 도입
- 로그인하지 않은 사용자의 보호된 페이지 접근을 막는 middleware 신규 도입
- 계좌 연동 배너 추가, lightbox 공통 컴포넌트 연결
- 비로그인 사용자 리다이렉트 처리, 소개/예약 페이지 문구 정비

## 이슈 및 리스크

### 신규 1:1 채팅방 자동 표시 누락

- **증상:** 펫시터가 예약을 수락해도 보호자 화면에 신규 1:1 채팅방이 자동으로 표시되지 않던 문제
- **해결:** 채팅방 생성 시 보호자 화면 자동 이동 및 표시 로직 추가

### 예약 확정 카드 실시간 미반영

- **증상:** 예약이 확정되어도 카드가 실시간으로 표시되지 않고 새로고침을 해야 보이던 문제
- **해결:** 실시간 반영 로직 수정

### 추가금 0원 결제 요청 가능

- **증상:** 채팅 페이지 추가금 요청 모달에서 금액이 0원인 결제 요청도 전송이 가능했던 문제
- **해결:** 0원 결제 요청 방지 로직 추가
