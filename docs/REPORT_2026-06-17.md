# 최종 프로젝트 진행 리포트 — 2026-06-17

---

## 진행 상황 요약

로그인/본인인증/유저 정보 로직을 다듬고, 실시간 채팅 수신 방식을 broadcast로 전환해 메시지 지연 문제를 해결함. 펫시터 지도와 상세 페이지를 더미데이터에서 Supabase 실데이터로 전환함. 구인게시판 CRUD를 구현하고 조회 로직을 API 라우트로 분리함.

---

## 주요 성과

- 로그인/로그아웃, 본인인증(verification), 유저 정보 로드 로직 정비
- 채팅 실시간 수신 방식을 broadcast로 전환해 즉시 반영 문제 해결
- 펫시터 지도 데이터 및 펫시터 상세 페이지를 Supabase 실데이터로 전환
- 구인게시판 CRUD 구현, 조회는 API 라우트로 분리하고 쓰기는 Server Action 유지

## 이슈 및 리스크

### 채팅 실시간 수신 지연

- **증상:** 보호자가 보낸 메시지가 펫시터 화면에 즉시 반영되지 않는 문제
- **해결:** 수신 방식을 broadcast로 전환 (`useChatMessages` 훅 로직 수정)

### 모바일/데스크톱 메시지 자동 스크롤 오류

- **증상:** 모바일/데스크톱 레이아웃이 동일한 ref를 바인딩해 항상 데스크톱 쪽 div만 스크롤되던 문제
- **해결:** 레이아웃별로 ref를 분리하여 수정
