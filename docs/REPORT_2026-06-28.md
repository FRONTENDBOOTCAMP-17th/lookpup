## 이슈 및 리스크

### 결제 완료 메시지 전송 실패 시 버튼 영구 잠김

- **증상:** 결제 완료 후 완료 메시지 전송이 실패하면 관련 버튼이 영구적으로 잠기는 문제
- **해결:** 실패 시에도 버튼 상태가 복구되도록 로직 수정

### 모바일 채팅 탭 전환 시 이전 room 뷰 잔존

- **증상:** 모바일에서 채팅 탭을 전환해도 이전 채팅방 뷰가 그대로 남고, `userId` 로딩 전 null 상태에서 보호자/펫시터가 혼동되는 문제
- **해결:** 탭 전환 및 사용자 판별 로직 수정

### 신고 대상 정보 오전달

- **증상:** 지원 목록 탭에서 펫시터가 보호자를 신고할 때 `targetId`와 `role`이 잘못 전달되는 문제
- **해결:** 신고 대상 전달 로직 수정

### 펫시터 별점 초기화 버그

- **증상:** 후기를 삭제하거나 새로 작성할 때 펫시터 별점이 0점으로 초기화되는 문제
- **해결:** 별점 재계산 로직 수정

### 리뷰 관리 페이지 첨부 사진 미표시

- **증상:** 리뷰 관리 페이지에서 첨부한 사진이 표시되지 않고, 탭 전환 시 불필요한 API가 재호출되는 문제
- **해결:** 이미지 렌더링 및 탭 전환 시 데이터 재요청 로직 수정
