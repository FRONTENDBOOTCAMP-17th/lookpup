## 이슈 및 리스크

### 신고 페이지 메모리 누수

- **증상:** 신고 페이지에서 검색 기능 사용 시 메모리 누수 발생
- **해결:** 검색 관련 로직 정리로 메모리 누수 및 안정성 개선

### admin 역할 표시 불일치

- **증상:** 신고 페이지에서 admin 역할 표시가 실제 권한과 불일치하고 이미지 key도 잘못 지정됨
- **해결:** 역할 표시 로직 및 이미지 key 수정

### 새 채팅방 미반영

- **증상:** 새 1:1 채팅방을 생성해도 펫시터 목록에 실시간으로 반영되지 않는 문제
- **해결:** 채팅방 생성 시 목록 갱신 로직 추가
