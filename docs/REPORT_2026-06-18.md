## 이슈 및 리스크

### 채팅방 빠른 전환 시 메시지 덮어씌움

- **증상:** 채팅방을 빠르게 전환하면 이전 방의 메시지가 현재 방에 남아 표시되는 문제
- **해결:** `useChatMessages` 훅에서 방 전환 시 메시지 상태를 정리하도록 수정

### 모바일 메시지 Enter 키 전송 오류 재발

- **증상:** conflict 해결 과정에서 모바일 레이아웃의 `onKeyDown` 핸들러가 누락되어 Enter 전송이 동작하지 않음
- **해결:** 누락된 핸들러 재추가

### 채팅방 진입 시 스크롤 위치 오류

- **증상:** 모바일에서 채팅방 진입 시 최신 메시지가 아닌 잘못된 위치가 표시되고, 이전 메시지 로드 시 스크롤 위치가 튐
- **해결:** 스크롤 방식 개선으로 진입 시 최신 메시지 위치 고정 및 이전 메시지 로드 시 위치 유지

### 채팅방 목록 미리보기 미갱신

- **증상:** broadcast 방식 특성상 메시지 발신자에게는 자신의 메시지가 오지 않아 목록 미리보기가 갱신되지 않는 문제
- **해결:** 메시지 전송 후 `updatePreview`를 직접 호출하도록 수정
