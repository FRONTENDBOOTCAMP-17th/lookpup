# lookpup 4차 리뷰 — 해결 가이드 (2026-06-11)

## 1. [필수] 빌드 복구 — 조인 캐스팅 4곳 (gyuhwa)

원인: Supabase가 조인(`select('*, users(...)')`)을 **배열**로 추론하는데 코드가 **객체**로 단언.

### 정석: gen types 사용
```bash
npx supabase gen types typescript --project-id <id> > src/types/database.types.ts
```
```ts
import { createClient } from '@supabase/supabase-js';
import type { Database } from '@/types/database.types';
const supabase = createClient<Database>(url, key);
// 이제 조인 결과 타입이 실제 모양으로 추론됨 → as 단언 불필요
```

### 단언이 꼭 필요하면: 모양을 실제와 맞추기
조인 대상이 1:N이면 배열, N:1이면 객체입니다. 실제 응답을 `console.log`로 한 번 찍어 모양을 확인하고 타입을 맞추세요.
```ts
// payments.ts:82 — users가 배열로 오면
const row = data as { users: { full_name: string }[] };
const fullName = row.users[0]?.full_name ?? '';

// 정말 객체가 맞다면(.single() 조인 등) 컴파일러를 설득
const row = data as unknown as { users: { full_name: string } };  // 최후의 수단
```
`as unknown as`는 "내가 책임진다"는 임시방편입니다. 4곳을 임시로 넘기더라도, gen types로 바꾸는 걸 백로그에 남겨두세요.

## 2. [필수] 회원탈퇴 실제 연결 (박규나 ↔ gyuhwa)

```tsx
// settings/withdraw/page.tsx
import { deleteUser } from '@/app/actions/...';        // gyuhwa의 액션
import { createClient } from '@/utils/supabase/client';

const [submitting, setSubmitting] = useState(false);

const handleDelete = async () => {
  if (submitting) return;
  setSubmitting(true);
  try {
    await deleteUser();                       // 1) 서버에서 소프트 삭제(deleted_at)
    await createClient().auth.signOut();      // 2) 세션 종료
    setDone(true);                            // 3) 그 다음에 완료 화면
    // router.replace('/'); 등 후처리
  } catch (e) {
    // 에러 토스트/메시지
  } finally {
    setSubmitting(false);
  }
};
```
주의: `deleteUser`가 `deleted_at`만 찍으면 `auth.users`(로그인 계정)는 남습니다. 탈퇴한 이메일로 재가입을 막거나 완전 삭제하려면, service-role 키로 Admin API(`auth.admin.deleteUser`)까지 서버에서 처리해야 합니다. 정책(소프트 vs 완전)을 팀이 먼저 정하세요.

또한 `proxy.ts`(미들웨어)에서 `deleted_at`이 있는 유저는 보호 라우트 접근을 막아주면 더 안전합니다.

## 3. [협업] "내 층은 빌드 통과로 머지" + CI 게이트

층(프론트/API/공통)으로 나눈 분담은 좋습니다. 대신 각 층이 빌드를 깨지 않게:

`.github/workflows/ci.yml`:
```yaml
name: CI
on: [push, pull_request]
jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: npm }
      - run: npm ci
      - run: npx tsc --noEmit
      - run: npm run build
```
이러면 타입 에러가 있는 PR은 머지가 막혀, gyuhwa님 층의 에러가 dev로 새지 않습니다.
