# lookpup(봐주개) 10차 리뷰 — 해결 가이드 (2026-06-22)

이번엔 시연 전에 꼭 고쳐야 할 [필수]가 없습니다. 두 블로커(회원탈퇴·Cloudinary)가 다 해결됐으니, 이 가이드는 "고치는 법"이라기보다 "기억해 둘 것"을 정리해 두는 쪽에 가깝습니다.

---

## 1. Cloudinary 서명 — 한 줄 노트만 남기기

지금 코드(`upload.ts`)는 서명을 SHA-256으로 만들고 있고, 리뷰에서 직접 올려 보니 업로드도 잘 됩니다. 그래서 더 손댈 건 없는데, 다만 이게 잘 도는 이유가 "여러분 Cloudinary 계정이 SHA-256 서명을 받아주기 때문"이라는 점만 기억해 두면 좋겠습니다.

- 팀 노트(README나 `docs/`)에 한 줄: "이미지 업로드 서명은 SHA-256을 사용한다(Cloudinary 계정 설정과 맞춰져 있음)."
- 혹시 나중에 Cloudinary 계정을 새로 만들거나 환경이 바뀌면 같은 코드가 `Invalid Signature`로 막힐 수 있는데, 그럴 땐 `upload.ts`의 `crypto.createHash("sha256")`를 계정 설정에 맞는 알고리즘으로 바꿔주면 됩니다.

당장 할 일은 아니고, "왜 SHA-256인지"를 기록으로 남겨 두면 다음에 이 코드를 보는 사람이 헤매지 않을 거라 적어 둡니다.

---

## 2. (참고) 회원탈퇴는 잘 닫혔습니다

`handleDelete`가 `deleteUser` → 에러 처리 → `clearUser` → `signOut` 순서로 정확히 연결됐습니다. 더 손볼 건 없고, 한 가지만 시연 전에 직접 눌러서 확인해 보세요. 실제 계정으로 탈퇴를 눌렀을 때 로그아웃되고 로그인 화면으로 돌아오는지 보는 겁니다. 실데이터로 도는 흐름이다 보니, 시연용 계정과 실제로 쓸 계정은 구분해서 테스트하시는 게 안전합니다.

---

## 3. 시연 운영 — 범위 합의

관리자 기능이 아직 없으니 오늘은 사용자 흐름 중심으로 가면 됩니다. 시연 전에 팀끼리 짧게 범위를 정하고 들어가면 좋겠습니다.

- 보여줄 핵심 동선: 메인 → 펫시터 목록/상세 → (로그인) → 구인게시판 글쓰기 → 후기 → 마이프로필.
- 가격/위치 입력이나 관리자처럼 아직 미완성인 부분은 "이 부분은 다음 단계에서 붙입니다" 정도로 설명을 미리 준비해 두면, 시연 중에 끊겨 보이지 않습니다.
