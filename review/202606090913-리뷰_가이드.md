# lookpup 2차 리뷰 — 해결 가이드 (2026-06-09)

## 1. 인증 마무리 — 로그아웃 + 루트 middleware + 보호 라우트

### 1-1. 로그아웃에 `signOut()` 추가
```tsx
// myprofile/page.tsx (로그아웃 버튼)
import { createClient } from "@/utils/supabase/client";

const handleLogout = async () => {
  const supabase = createClient();
  await supabase.auth.signOut();   // 세션 종료(쿠키 제거)
  router.push("/auth/login");
};
...
<button onClick={handleLogout}>로그아웃</button>
```

### 1-2. 루트 `middleware.ts` 추가 (이미 만든 헬퍼 연결)
프로젝트 루트(또는 `src/`)에 `middleware.ts`를 만들고 헬퍼를 호출합니다.
```ts
// src/middleware.ts  (src 구조면 src 안에)
import { type NextRequest } from "next/server";
import { updateSession } from "@/utils/supabase/middleware";

export async function middleware(request: NextRequest) {
  return await updateSession(request);
}

export const config = {
  // 정적 파일 제외하고 전 경로에서 세션 갱신
  matcher: ["/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)"],
};
```
이러면 서버에서 세션이 자동 갱신됩니다.

### 1-3. 보호 라우트 차단
`updateSession`(헬퍼) 안에서, 로그인 안 했고 보호 경로면 로그인으로 보냅니다.
```ts
// utils/supabase/middleware.ts 내부, getUser() 이후
const { data: { user } } = await supabase.auth.getUser();
const protectedPaths = ["/myprofile", "/mypets", "/petsitters/", "/board/write"];
const needsAuth = protectedPaths.some((p) => request.nextUrl.pathname.startsWith(p));
if (!user && needsAuth) {
  const url = request.nextUrl.clone();
  url.pathname = "/auth/login";
  return NextResponse.redirect(url);
}
```
> 확인: 로그아웃 후 `/myprofile` 직접 접근 → 로그인으로 튕기는지.

## 3. 카카오맵 살리기

### 3-1. 환경변수 이름
`.env.local`에 **NEXT_PUBLIC_ 접두사 + 공백 없이**:
```
NEXT_PUBLIC_KAKAO_MAP_KEY=발급받은_JavaScript_키
```
(현재 `KAKAO_MAP_KEY = ...`는 서버에서만 보이고 공백까지 값에 들어갑니다.)

### 3-2. 카카오 개발자 콘솔 도메인 등록
[Kakao Developers] → 내 앱 → 플랫폼 → Web → 사이트 도메인에 `http://localhost:3000`(개발), 배포 도메인 추가. JavaScript 지도는 등록 도메인에서만 뜹니다.

### 3-3. 지도 컨테이너 높이 확인
지도를 감싼 div에 실제 높이가 있어야 합니다(`h-100`이 Tailwind에 없으면 0). 예: `className="h-96"` 또는 `style={{ height: 400 }}`.

### 3-4. (선택) 리렌더 최적화
```tsx
const markers = useMemo(() => petsitters.map(p => ({ id: p.id, lat: p.lat, lng: p.lng, certified: p.certified })), [petsitters]);
<KakaoMap markers={markers} ... />
```

## 5. RLS (실데이터 전)
Supabase 대시보드에서 모든 테이블 RLS on + "본인 데이터만" 정책. 예:
```sql
alter table public.bookings enable row level security;
create policy "own bookings" on public.bookings for select to authenticated
  using (user_id = (select auth.uid()));
```
service-role 키가 "Invalid"로 떴으니, 대시보드에서 키도 재발급/확인하세요.
